# Expense Tracker - Python Programming Project

## 📋 Project Overview
A simple and user-friendly Expense Tracker built in Python to help users track their daily expenses, manage their budget, and view spending summaries.

This project was built as part of my Python learning journey and internship practice.

## ✨ Features
- Add new expenses with category and amount
- View all expenses in a list
- Calculate total expenses
- Delete expenses
- Simple and easy to use menu system
- Data stored in a Python list

## 🛠️ Technologies Used
- Python 3
- VS Code
- Git & GitHub
